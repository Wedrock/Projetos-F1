# Box Box

Esta pasta contém o app completo (backend, frontend e Docker).

A documentação, com vídeo, lista de recursos e o passo a passo para rodar, está no [README principal](../README.md).

Para subir o app:

```bash
cp .env.example .env
docker compose up -d
```

Depois abra [http://localhost:8000](http://localhost:8000).
